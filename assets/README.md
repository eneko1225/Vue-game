# Assets

Both packs are by 3dpyramid on OpenGameArt and released under CC0 (public domain).

- `knight-*.webp`: [RPG Character Knight](https://opengameart.org/content/rpg-character-knight), "Outlined" image sequences (30 fps) scaled to 392×308 and tiled into one row per animation.
- `monster.png`: "Amphibian" from [Characters Pack](https://opengameart.org/content/characters-pack), x1.
